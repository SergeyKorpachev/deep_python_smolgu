## Экзамен.

Экзаменом на курсе является сдача практических задач. Экзамен проводится в сессионной период.
Экзамен сдаётся по выбору. В случае желания студента повысить баллы за среднее по всем домашним заданиям.

На экзамене нельзя пользоваться ноутбуком или какими-либо другими заготовленными материалами с полезной информация для ответа.

В качестве пересдачи соответственно такой же формат экзамена. При этом нет блокирующих элементов контроля.

## Правила / формула оценивания.

```Итоговая оценка = max(О_Среднее_ДЗ, О_Экзамен)```

* `О_Среднее_ДЗ` - средняя оценка за домашние задания (сколько-то штук);
* `О_Экзамен` - оценка за экзамен.

То есть выбирается максимум между средним баллом за все домашние задания и баллов за экзамен (в случае сдачи). Экзамен выступает способом повысить балл за среднее по всем домашним заданиям.

Округление оценки - округляется только итог. Округление арифметическое, блокирующих оценок нет.

Домашние задания выдаются для самостоятельного выполнения в ipynb-файлах (по умолчанию). Всего будет сколько-то домашних задания по курсу.

Каждое домашнее задание имеет 1 дедлайн: жесткий. Задания выдаются примерно на весь семестр. После жесткого дедлайна задачи не оцениваются.
Детали сдачи нужно обговаривать с лектором / семинаристом. По умолчанию с семинаристом.
